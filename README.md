# Task Tracker — Календарная канбан-доска

Планируйте задачи по дням, двигайте их по статусам и не теряйте фокус на том, что важно сегодня.

## Что это

Task Tracker — это доска задач, привязанная к календарю. Вместо бесконечного списка дел вы видите задачи конкретного дня и управляете их статусами: от идеи до выполнения.

## Как работает

- **Выбираете день** — переключайтесь между датами стрелками, кнопкой «Сегодня» или календарём.
- **Добавляете задачи** — нажмите «+» в любой колонке и запишите, что нужно сделать.
- **Двигаете по статусам** — перетаскивайте задачи между колонками «Новые», «В процессе» и «Сделаны».
- **Группируете** — объединяйте задачи по категориям (swimlanes), чтобы видеть контекст.
- **Назначаете ответственных** — указывайте, кто ведёт задачу, и фильтруйте доску по людям.
- **Массовые операции** — выделите несколько задач и перенесите или удалите их разом.
- **Перенос несделанного** — одной кнопкой сдвиньте все незавершённые задачи на другой день.

## Возможности

| Возможность | Описание |
|-------------|----------|
| Календарная навигация | Переключайтесь между днями, чтобы видеть задачи только выбранной даты |
| Три колонки статусов | «Новые», «В процессе», «Сделаны» — классический канбан |
| Drag-and-drop | Перетаскивайте задачи между колонками и меняйте порядок |
| Swimlane-группировка | Группируйте задачи по категориям внутри каждого дня |
| Ответственные | Назначайте исполнителей и фильтруйте доску по ним |
| Массовое перемещение | Выбирайте несколько задач и переносите их на другую дату |
| Массовое удаление | Удаляйте отобранные задачи одним действием |
| Перенос несделанных | Переносите все незавершённые задачи на выбранный день |

## Горячие клавиши

- **← →** — предыдущий / следующий день
- **Пробел / Enter** на задаче — выделить для массовой операции

## Тёмная тема

Приложение использует современную тёмную тему в стиле редакторов кода с моноширинной типографикой и циановым акцентом. Приятно для глаз при длительной работе.
