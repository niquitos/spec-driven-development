# Чек-лист требований: Ясность и полнота — Swimlane

**Назначение**: Проверка спецификации на неоднозначности, пропуски и неясные формулировки перед переходом к планированию
**Создано**: 2026-05-25
**Функция**: [spec.md](../spec.md)
**Глубина**: Стандартная (~25-30 элементов)
**Фокус**: Неоднозначности/ясность, Полнота/пропуски
**Аудитория**: Автор (самопроверка)

## Неоднозначности и ясность

- [ ] CHK001 Определено ли, какой тип ввода представляет поле «Swimlane» — произвольный текст, выпадающий список существующих значений или автодополнение? [Ясность, Spec §FR-006]
- [ ] CHK002 Куда именно помещается новый swimlane при автоматическом создании — в начало, конец или по алфавиту? [Ясность, Spec §FR-007]
- [ ] CHK003 Что означает «мгновенно» в SC-002 — есть ли конкретный порог в миллисекундах, или это достаточно уточнить как «без перезагрузки страницы»? [Ясность, Spec §SC-002]
- [ ] CHK004 Какой именно элемент управления используется для сворачивания/разворачивания swimlane — кнопка, иконка, клик по заголовку? [Ясность, Spec §FR-003]
- [ ] CHK005 Если swimlane регистронезависимы (FR-011), то в каком регистре отображается название — как ввёл первый пользователь, как ввёл последний, или всегда с заглавной буквы? [Ясность, Spec §FR-011]
- [ ] CHK006 В граничном случае указано, что название удалённого swimlane «сохраняется в системе для возможного повторного использования» — противоречит ли это FR-009, который требует «удалять пустой swimlane с доски»? Разъяснена ли разница между удалением с доски и сохранением в системе? [Согласованность, Spec §FR-009]
- [ ] CHK007 Допущение «Drag-and-drop поддерживается только в горизонтальном направлении» противоречит пользовательской истории US-4, где задача перетаскивается из одного swimlane в другой (вертикальное перемещение). Разъяснено ли, как именно работает вертикальный drag-and-drop между swimlane? [Согласованность, Spec §US-4 vs Допущения]
- [ ] CHK008 Определено ли, что происходит при одновременном изменении swimlane несколькими пользователями — последнее изменение побеждает, или есть механизм разрешения конфликтов? [Ясность, Gap]
- [ ] CHK009 FR-012 требует отображать количество задач в каждом swimlane, но ни один сценарий приёмки не проверяет это требование. Следует ли добавить сценарий для FR-012 или это требование избыточно? [Полнота, Spec §FR-012]

## Полнота и пропуски

- [ ] CHK010 Определён ли порядок отображения swimlane на доске — по алфавиту, по дате создания, по количеству задач, или пользователь может менять порядок? [Gap]
- [ ] CHK011 Определено ли начальное состояние swimlane при первом открытии доски — все развёрнуты, все свёрнуты, или есть логика по умолчанию? [Gap, Spec §FR-003]
- [ ] CHK012 Указано ли, что происходит с состоянием сворачивания при изменении набора swimlane (добавление/удаление задачи создаёт новый swimlane)? Сохраняются ли свёрнутые состояния новых swimlane? [Gap, Spec §FR-005]
- [ ] CHK013 Описано ли поведение доски, когда все задачи находятся в swimlane «Без категории» (т.е. нет ни одного именованного swimlane)? [Gap]
- [ ] CHK014 Определена ли валидация для названия swimlane — можно ли указать пустую строку, пробелы, спецсимволы, очень длинные имена? [Gap, Spec §FR-006]
- [ ] CHK015 Указано ли ограничение на максимальное количество swimlane на одной доске? Что происходит при очень большом числе уникальных значений? [Gap]
- [ ] CHK016 Описано ли, что происходит с состоянием сворачивания при смене пользователя или при работе с одной доской разными пользователями — является ли состояние сворачивания персональным? [Gap, Spec §FR-005]
- [ ] CHK017 Указано ли поведение при drag-and-drop задачи в swimlane «Без категории» — очищается ли поле swimlane у задачи? [Gap, Spec §US-4]
- [ ] CHK018 Определено ли, что происходит при drag-and-drop, если целевой swimlane ещё не существует — создаётся ли он автоматически (как при вводе через поле)? [Gap, Spec §US-4 vs §FR-007]
- [ ] CHK019 Описаны ли требования к доступности (accessibility) — навигация по swimlane с клавиатуры, скринридеры, ARIA-атрибуты? [Gap]
- [ ] CHK020 Указано ли, что происходит при удалении swimlane через удаление всех его задач — уведомляется ли пользователь, что swimlane исчезнет? [Gap, Spec §FR-009]
- [ ] CHK021 Определено ли поведение при пустой доске (нет задач вообще) — отображается ли swimlane «Без категории» как пустой? [Gap]

- [ ] CHK025 SC-001 и SC-004 содержат конкретные временные пороги (2 секунды), но SC-002 использует «мгновенно» — следует ли заменить на измеримый порог или уточнить, что «мгновенно» означает «без серверного запроса»? [Измеримость, Spec §SC-002]
