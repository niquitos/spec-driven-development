### Правила валидации Swimlane

- `Swimlane` — nullable string, максимальная длина 100 символов
- Пустые строки и строки из пробелов нормализуются в `null` (аналогично `Assignee`)
- Регистронезависимое сравнение: «Фронтенд» и «фронтенд» — одна и та же группа (FR-011)
- Отображаемое имя — вариант написания, введённый первым (FR-011)
- При удалении значения (очистка поля) задача перемещается в «Без категории»
- **Превышение длины**: если значение > 100 символов — frontend обрезает ввод (maxlength), backend возвращает `400 Bad Request` с детальным сообщением
- **Пробельные строки**: `string.IsNullOrWhiteSpace(swimlane)` → `null` как на backend, так и на frontend (trim + empty → null)

### Ключ нормализации (CHK012, CHK015, CHK047)

Для обеспечения консистентности между backend, frontend и localStorage используется единая функция нормализации ключей:

```
normalizeKey(value) = value.toLowerCase()
```

- **Backend** (`GetSwimlanesAsync`): `.GroupBy(t => t.Swimlane!.ToLower())` — группирует по lowercase-ключу, сохраняет оригинальное написание первого вхождения
- **Frontend** (группировка): `normalizeSwimlaneKey(task.swimlane ?? "Без категории")` → lowercase-ключ
- **Frontend** (droppableId): `{normalizeSwimlaneKey(swimlane)}:{TaskStatus}` — lowercase-ключ
- **Frontend** (localStorage): `Set<string>` нормализованных ключей — совпадает с droppableId и ключами группировки
- **«Без категории»**: нормализованный ключ = `"без категории"`, отображаемое имя = `"Без категории"`

## Виртуальные сущности (не хранятся в БД)

### Swimlane (виртуальная группировка)

Swimlane НЕ является отдельной сущностью в БД. Это виртуальная группировка, полностью определяемая уникальными значениями поля `Swimlane` у задач.

| Атрибут | Описание |
|---------|----------|
| Ключ | Нормализованное (lowercase) значение поля `Swimlane`, или `"без категории"` для `null` |
| Отображаемое имя | Оригинальное написание первого вхождения (из БД для существующих, из ввода для новых) |
| Порядок | «Без категории» — всегда первый, остальные — по алфавиту (case-insensitive) |
| Задачи | Все задачи с соответствующим значением `Swimlane` (или `null` для «Без категории») |
| Сворачивание | UI-состояние, хранится в localStorage по нормализованному ключу, не в БД |
| Количество задач | Общее количество задач в swimlane (суммарно по всем колонкам), отображается в заголовке рядом с названием |

### Переходы состояний

```
Задача без swimlane (null)  ←→  Задача со swimlane (значение)
    │                                    │
    └── Очистка поля swimlane            └── Указание/изменение swimlane
```

- Установка значения swimlane → задача перемещается в соответствующую группу
- Очистка поля swimlane → задача перемещается в «Без категории»
- Переименование swimlane у одной задачи → не влияет на другие задачи с тем же значением (каждое значение — независимое)
- Удаление единственной задачи в swimlane → swimlane перестаёт отображаться на доске

### Визуальное представление (CHK001, CHK008)

Swimlane отображается как **горизонтальная полоса (строка)**, протяжённая на все колонки статуса. Структура доски — матрица:

```
┌──────────────────────────────────────────────────────────┐
│ Заголовок swimlane "Без категории" (3)         [▾]      │
├─────────────┬──────────────────┬────────────────────────┤
│ Новые (1)   │ В работе (1)     │ Готово (1)             │
│ ┌─────────┐ │ ┌──────────────┐ │ ┌────────────────────┐  │
│ │ Задача  │ │ │ Задача       │ │ │ Задача            │  │
│ └─────────┘ │ └──────────────┘ │ └────────────────────┘  │
├─────────────┴──────────────────┴────────────────────────┤
│ Заголовок swimlane "Фронтенд" (2)               [▾]      │
├─────────────┬──────────────────┬────────────────────────┤
│             │ В работе (1)     │ Готово (1)             │
│ (пусто)     │ ┌──────────────┐ │ ┌────────────────────┐  │
│             │ │ Задача       │ │ │ Задача            │  │
│             │ └──────────────┘ │ └────────────────────┘  │
└─────────────┴──────────────────┴────────────────────────┘
```

Каждый swimlane — это строка матрицы. Каждый swimlane содержит все три колонки статуса, даже если в некоторых из них нет задач (пустая ячейка остаётся Droppable-областью).

### Свёрнутый swimlane

Свёрнутый swimlane отображается как узкая горизонтальная полоса с названием и количеством задач, без карточек задач:

```
┌──────────────────────────────────────────────────────────┐
│ Заголовок swimlane "Без категории" (3)         [▸]      │
└──────────────────────────────────────────────────────────┘
```

Каждая ячейка свёрнутого swimlane остаётся Droppable-областью — задача может быть перетащена в свёрнутый swimlane (задача добавится, swimlane не разворачивается автоматически).

Группировка выполняется на frontend по загруженным задачам — нет отдельного API для получения задач по swimlane.

### Порядок групп

1. «Без категории» (ключ `"без категории"` — задачи с `swimlane: null`)
2. Остальные — по алфавиту ключа (case-insensitive, нормализовано через `.toLowerCase()`)

### Взаимодействие с фильтрами (CHK006, CHK048)

Фильтр по assignee и группировка по swimlane работают ортогонально:
1. Сначала фильтрация по assignee (backend-side)
2. Затем группировка отфильтрованных задач по swimlane (frontend-side)
3. Если в swimlane нет задач после фильтрации — swimlane не отображается
