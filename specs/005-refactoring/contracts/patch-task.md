# API Contract: PATCH /api/tasks/{id}

**Дата**: 2026-05-28 | **Спецификация**: [spec.md](../spec.md)

## Эндпоинт

```
PATCH /api/tasks/{id}
```

Частичное обновление задачи. Только переданные поля обновляются, отсутствующие поля остаются без изменений.

## Параметры пути

| Параметр | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| id | int | Да | Идентификатор задачи |

## Заголовки запроса

```
Content-Type: application/json
```

## Тело запроса

JSON-объект с полями, которые нужно обновить. Все поля необязательные.

```json
{
  "title": "Новое название",
  "status": "InProgress",
  "swimlane": "Фронтенд"
}
```

### Семантика полей

| Поле | Тип | Передано | Отсутствует | Описание |
|------|-----|---------|-------------|----------|
| title | string? | Обновить название | Не изменять | Max 200 символов |
| description | string? | Обновить описание; `""` → очистить | Не изменять | Max 2000 символов |
| status | string? | Обновить статус | Не изменять | `"New"`, `"InProgress"`, `"Done"` |
| date | string? | Обновить дату | Не изменять | ISO 8601 (`"2026-05-28"`) |
| order | int? | Обновить порядок | Не изменять | Позиция в колонке |
| assignee | string? | Обновить/очистить исполнителя; `""` → очистить | Не изменять | Max 100 символов |
| swimlane | string? | Обновить/очистить свимлейн; `""` → очистить | Не изменять | Max 100 символов |

### Примеры запросов

**Изменить только статус (перетаскивание в другую колонку)**:
```json
{
  "status": "InProgress",
  "order": 2
}
```

**Изменить свимлейн (перетаскивание между свимлейнами)**:
```json
{
  "status": "InProgress",
  "order": 0,
  "swimlane": "Бэкенд"
}
```

**Очистить исполнителя**:
```json
{
  "assignee": ""
}
```

**Очистить свимлейн**:
```json
{
  "swimlane": ""
}
```

**Пустой запрос (нет изменений)**:
```json
{}
```
Возвращает 200 OK, задача остаётся без изменений.

## Ответы

### 200 OK

Успешное обновление. Тело ответа отсутствует. Возвращается также при пустом теле запроса (задача не изменяется).

### 204 No Content

Успешное обновление с изменениями. Тело ответа отсутствует.

> **Примечание**: 200 OK и 204 No Content семантически эквивалентны для клиента — в обоих случаях задача обновлена (или не требовала изменений при пустом теле). Реализация может использовать один код для всех успешных PATCH-запросов.

### 400 Bad Request

Ошибка валидации или неверный формат запроса.

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "Title": ["Title must not exceed 200 characters."],
    "Id": ["The value 'abc' is not valid."]
  }
}
```

### 404 Not Found

Задача с указанным id не найдена.

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.4",
  "title": "Not Found",
  "status": 404,
  "detail": "Task with id 999 not found."
}
```

## Отличия от PUT /api/tasks/{id}

| Аспект | PUT | PATCH |
|--------|-----|-------|
| Обязательные поля | Все (кроме Description, Assignee, Swimlane) | Нет обязательных полей |
| Отсутствующее поле | Устанавливается в значение по умолчанию | Не изменяется |
| `null` для строки | Обнуляет поле | Очищает поле |
| `""` для строки | Устанавливает пустую строку | Очищает поле (нормализуется в null) |
| Случай использования | Форма редактирования | Перетаскивание, частичные обновления |
| Идемпотентность | Да (полная замена) | Нет (частичное обновление) |

## Фронтенд-интеграция

### taskApi.ts — новый метод

```typescript
async patchTask(id: number, dto: Partial<UpdateTaskDto>): Promise<void> {
  await api.patch(`/tasks/${id}`, dto);
}
```

### taskStore.ts — moveTask (исправленный)

```typescript
// Было: taskApi.updateTask(id, { ... }) без swimlane
// Стало: taskApi.patchTask(id, { status, order, swimlane }) — только изменённые поля
```

### taskStore.ts — rollback при ошибке

```typescript
try {
  await taskApi.patchTask(id, { status, order, swimlane });
} catch (error) {
  // Восстановить исходное состояние
  set((state) => ({ tasks: originalTasks }));
  showNotification('Ошибка сохранения. Задача возвращена на исходную позицию.');
}
```
