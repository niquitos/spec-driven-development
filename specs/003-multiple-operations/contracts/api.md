## Новый эндпоинт

### POST /api/tasks/bulk/move-incomplete-to-tomorrow

Переносит все невыполненные задачи (Status != Done) на завтрашний день.

**Запрос**: Тело отсутствует (параметры не требуются)

```json
POST /api/tasks/bulk/move-incomplete-to-tomorrow
Content-Type: application/json
```

**Ответ 200 OK**:

```json
{
  "moved": 5,
  "targetDate": "2026-05-24T00:00:00Z"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| moved | int | Количество перенесённых задач. 0, если нет невыполненных задач |
| targetDate | DateTime | Целевая дата (завтра от текущей даты сервера) |

**Ответ 200 OK (нет задач для переноса)**:

```json
{
  "moved": 0,
  "targetDate": "2026-05-24T00:00:00Z"
}
```

**Определение «завтра»**: `DateTime.UtcNow.Date.AddDays(1)`. Сервер определяет завтрашнюю дату на основе UTC.

## Ограничения

- Операция «Перенести на завтра» не принимает список IDs — сервер сам находит все невыполненные задачи
- Операция не требует аутентификации (приложение не имеет системы авторизации)
- Нет ограничений на количество задач — переносятся все невыполненные задачи во всём хранилище
- Операция не возвращает список перенесённых IDs — только количество
