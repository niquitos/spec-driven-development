# Задачи: Массовые операции над задачами

**Ввод**: Проектные документы из `/specs/003-multiple-operations/`

**Предварительные требования**: plan.md (обязательно), spec.md (обязательно для пользовательских историй), research.md, data-model.md, contracts/

**Организация**: Задачи сгруппированы по пользовательским историям для обеспечения независимой реализации и тестирования каждой истории.

## Формат: `[ID] [P?] [История] Описание`

- **[P]**: Может выполняться параллельно (разные файлы, нет зависимостей)
- **[История]**: К какой пользовательской истории относится задача (US1, US2, US3)

## Контекст реализации

Большая часть инфраструктуры уже реализована: выделение задач (TaskCheckbox), BulkDeleteCommand, BulkMoveCommand, BulkActionsPanel, bulkDelete/bulkMove в taskStore и taskApi. Основная新增-работа — кнопка «Перенести на завтра» (US3), исправление window.confirm (US1) и добавление обратной связи для всех массовых операций (FR-017).

**Ключевые находки из ревью**:
- `handleBulkMove` НЕ использует `window.confirm` — только `handleBulkDelete` (FR-005 затрагивает только удаление)
- `bulkDelete` и `bulkMove` уже снимают выделение (`selectedTaskIds: []`), но не показывают обратную связь по количеству затронутых задач
- В проекте нет системы уведомлений (toast/snackbar) — нужно добавить для FR-017 и FR-020

## Заметки

- Задачи [P] = разные файлы, нет зависимостей
- Метка [US*] привязывает задачу к конкретной пользовательской истории для трассировки
- US1 и US2 в основном реализованы — задачи добавляют обратную связь (FR-017), обработку ошибок (FR-013) и убирают window.confirm (FR-005)
- US3 — основная новая функциональность, требующая изменений на всех слоях
- T002 (Toast) — новый компонент, необходимый для FR-017 (обратная связь) и FR-020 (сообщения об отсутствии задач)
- FR-005 (без подтверждений): `handleBulkMove` НЕ использует `window.confirm` — затрагивает только `handleBulkDelete`
- FR-011 (снятие выделения): `bulkDelete` и `bulkMove` уже снимают выделение через `selectedTaskIds: []`
- Делайте коммит после каждой задачи или логической группы
- Останавливайтесь на любой контрольной точке для независимой валидации истории
